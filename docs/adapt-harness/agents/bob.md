# Worker agent: IBM Bob Shell

**Status: verified.** This is the path the repository runs in production. Every
item below is read from the code. Keeping Bob means the SPEC marks each row
**keep**; the snippets are here so a SPEC can quote what already exists.

## Where each concern lives

| Concern           | File                                               | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Invocation        | `src/agentRunner.js`, `case 'bob'`                 | `bob run --format stream-json --trust --accept-license [--team-id <id>] [--max-cost N] [--max-turns N] [--disable-tool-groups G] "<prompt>"`; cwd is the per-item workspace; stdin ignored; 10-minute timeout (SIGTERM, then SIGKILL after 10 s). Output is NDJSON: the runner returns the assistant text, paired tool calls and the result event's `stats`, and saves `agent-output.txt` and `agent-events.ndjson`. Seen live on Bob 2.0.0: assistant text streams as token-level `message` pieces with no `delta` flag (the runner concatenates consecutive pieces), Bob's own `_[Continuing response due to length limit...]_` piece is dropped, and `result` carries no `last_message` and no token fields. `BOB_OUTPUT_FORMAT` (`stream-json` default, `pretty` kill switch that keeps the caps), `BOB_MAX_COST`, `BOB_MAX_TURNS` and `BOB_DISABLE_TOOL_GROUPS` (unset or `0` omits the flag) |
| Authentication    | `.env.example`, `SECRET_KEYS` in `.env`            | `BOB_API_KEY` (Inference scope). `BOB_TEAM_ID` only for a general-type key. `BOB_INSTANCE_ID` when the key spans instances                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| MCP configuration | `src/api/mcpConnection.js` `writeBobMcpHeaders`    | rewrites `~/.bob/settings/mcp.json` with the server URL, `Authorization` and `X-MCP-Session` headers on every refresh                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Cost              | `src/api/bobCredits.js`, `src/api/creditLedger.js` | per-run spend from the result record's `stats.session_costs`, with the balance delta from the Bob gateway admin API as the fallback and the remaining balance; spend recorded per item. `BOB_GATEWAY_BASE_URL` for a non-us-east instance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Install           | `Dockerfile`, the `---- Bob Shell ----` block      | pinned tarball from IBM Cloud Object Storage, SHA-256 checked, installed with `npm install -g`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

| Skills and rules  | `src/reviewBundle.js`                              | copies `.bob/skills/carbon-builder` into each workspace and writes `.bob/rules/01-output.md`; Bob reads both from the workspace                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
