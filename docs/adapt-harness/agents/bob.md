# Worker agent: IBM Bob Shell

**Status: verified.** This is the default path, `src/agents/bob.js`, and the one
the repository ran in production before Claude was added. Every item below is
read from the code. Keeping Bob means the SPEC marks each row **keep**; the
snippets are here so a SPEC can quote what already exists. The adapter contract
is in `docs/HARNESS.md` section 4.

## Where each concern lives

| Concern           | File                                                         | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Invocation        | `src/agents/bob.js` `buildArgs`, run by `src/agentRunner.js` | `bob run --format stream-json --trust --accept-license [--team-id <id>] [--max-cost N] [--max-turns N] [--disable-tool-groups G] "<prompt>"`; cwd is the per-item workspace; stdin ignored; 10-minute timeout (SIGTERM, then SIGKILL after 10 s). Output is NDJSON: the runner returns the assistant text, paired tool calls and the result event's `stats`, and saves `agent-output.txt` and `agent-events.ndjson`. Bob's wire format is parsed in `parseEvent`, and its continuation notice and `attempt_completion` result are handled in `finalizeText`, both in the adapter. Seen live on Bob 2.0.0: assistant text streams as token-level `message` pieces with no `delta` flag (the collector joins consecutive pieces), Bob's own `_[Continuing response due to length limit...]_` piece is dropped, and `result` carries no `last_message` and no token fields. `BOB_OUTPUT_FORMAT` (`stream-json` default, `pretty` kill switch that keeps the caps), `BOB_MAX_COST`, `BOB_MAX_TURNS` and `BOB_DISABLE_TOOL_GROUPS` (unset or `0` omits the flag) |
| Authentication    | `.env.example`, the `SECRET_KEYS` default in `deploy_ce.sh`  | `BOB_API_KEY` (Inference scope). `BOB_TEAM_ID` only for a general-type key. `BOB_INSTANCE_ID` when the key spans instances                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| MCP configuration | `src/api/mcpConnection.js` `writeBobMcpHeaders`              | rewrites `~/.bob/settings/mcp.json` with the server URL, `Authorization` and `X-MCP-Session` headers on every refresh. Each review runs against a private copy under `<bundle>/home/.bob/` (`seedBobHome`, `refreshBobMcp` in `src/reviewBundle.js`, reached through the adapter's `seedHome`). `getCredentials` reads the same file for other agents                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Cost              | `src/api/bobCredits.js`, `src/api/creditLedger.js`           | per-run spend from the result record's `stats.session_costs`, with the balance delta from the Bob gateway admin API as the fallback and the remaining balance; spend recorded per item. `BOB_GATEWAY_BASE_URL` for a non-us-east instance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Install           | `Dockerfile`, the `---- Bob Shell ----` block                | pinned tarball from IBM Cloud Object Storage, SHA-256 checked, installed with `npm install -g`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Seeded state      | `Dockerfile`, the `mkdir -p /home/app/.bob` block            | licence consent in `~/.bob/settings.json`, `/workspace` in `~/.bob/trustedFolders.json`, an empty `~/.bob/settings/mcp.json`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Skills and rules  | `src/agents/bob.js` `prepareBundle`                          | copies `.bob/skills/carbon-builder` into each workspace, writes `.bob/rules/01-output.md` and a `.env` holding `BOB_API_KEY` (mode 0600); Bob reads the rules and skill from the workspace                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Health check      | `src/api/healthChecks.js` `checkAgent`, `checkBobCredits`    | `bob --version` under `BOB_CHECK_TIMEOUT_MS`, then checks `BOB_API_KEY` is set; the Bobcoins tile reads the gateway balance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
